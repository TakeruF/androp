# 从共享菜单发送

简体中文 · [English](SHARING.en.md)

从 0.3.0 起，anDrop 可接收“文件”“照片”等应用共享的文件。0.4.0 起，iOS 26 及以上通过本体交接支持持续后台处理。

1. 首次打开 anDrop 本体，允许蓝牙和本地网络访问；与接收设备连接同一 Wi-Fi。
2. 在其他应用选择文件／照片并共享到 anDrop。找不到时横向滚动共享候选或打开“更多”。
3. 确认导入文件名和类型，选择接收设备；互传设备需开启公开可见。
4. iOS 26 起按“準備を完了”关闭共享界面，手动打开 anDrop 本体开始发送。iPad 分屏中本体已经打开时按“準備済みの送信を開始”。
5. 对方批准后传输；开始后可切换应用。等待对方完成确认，不把仅发送完字节当作完成。

iOS 26 以前需要在共享界面内完成发送。关闭正在传输的共享界面会中止旧系统中的传输。共享扩展只发送，接收请打开本体。已在本体 IP 注册的华为设备也会检查，但[华为发送仍属未完成实机验证的试验功能](HUAWEI.md)。

每批最多 16 文件／原始总大小 64 MiB。不支持文件夹、URL／文本对象或保留 Live Photo 配对的专门转换；文本文件可作为文件发送。扩展声明的文件／图片／视频类型只决定出现条件，实际导入仍逐项验证。

优先使用提供方文件 URL，并在临时 URL 的回调结束前完成复制；保留原名与字节。支持文件、数据表示与受限的旧式 item 回退。名称冲突仅修改私有副本的名字。取消后不因迟到回调重新创建准备目录。iOS 26 交接再复制到私有 App Group，不依赖提供方临时文件继续存在。

“診断ログをコピー”复制本扩展的有限诊断，必要时向下滚动。导入开始前即记录数量和已知阶段，错误仅包含受限原因／代码；不输出路径、文件名、内容、IP、密钥或未知错误说明。诊断由用户自行发送。

见[后台传输](BACKGROUND.md)与[验证范围](VALIDATION.md)。
