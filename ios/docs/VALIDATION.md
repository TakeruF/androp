| 范围 | 结果与边界 |
| --- | --- |
| OPPO ↔ iPhone 16 | 用户已报告双向传输成功；不表示所有格式与机型已覆盖 |
| 多照片共享 | 0.3.1 修复共享导入；0.3.2 将原始总大小上限从 16 MiB 提高至 64 MiB，用户报告可选择五张照片的接收设备；此报告本身不证明五张已全部传完 |
| macOS 上的核心测试 | 0.5.0 的 59 个测试成功，包含共享导入、路由、真实 TLS / WebSocket / HTTPS、归档、后台交接和华为协议 |
| 独立华为接收参考实现 | 本仓库 macOS 接收逻辑参与本机互操作测试；许可、拒绝、篡改完成应答、发送中止四种条件通过；七文件、超过 20 MiB，含空文件、日文原名和 `manifest.json`，逐文件内容一致且验证 DONE ACK |
| iPhone 16 型模拟器 / iOS 26.5 | 总计 66 项，63 项通过，跳过两项实机后台测试和一项缺少测试照片的可选 Photos 测试；核心为 58 项，其余包括本体、共享交接与华为设置 UI |
| iPad mini 型模拟器 / iOS 26.5 | 本体、共享至本体交接、华为 IP 输入及注销操作通过；曾修复父级可访问性 ID 覆盖子级输入框 ID 的问题 |
| iPhone 16 / iOS 26.7.1 | 0.5.0 签名构建与安装版本检查通过；最新版完整后台路径、Keychain 持久键与实机画面未完成确认 |
| 早期后台开发构建 | iPhone 16 本机 20 MiB TLS 传输在后台完成，系统进度有真实字节数；此结果不覆盖后续所有修改，也不是 OPPO / 华为的后台互操作证明 |
| HUAWEI Pura 70 / HarmonyOS 7 | 计划实机目标；当前 iOS 华为功能未在该设备验证，实机测试暂缓 |

华为参考测试仅调整初始 MetaNode 通知的发起顺序，之后使用未修改的 macOS 认证、解密与文件接收逻辑；它不是华为硬件的保存、图库、速度或稳定性证明。华为接收和自动发现未实现。

模拟器不支持此持续后台任务，测试确认前台回退行为。曾在同一主机并发 TLS 测试时出现超时，随后直列测试通过；这不应写成实机协议失败。

复现命令与测试脚本见 [README](../README.md)。可选参考试验需要本仓库 macOS 开发 Python 环境，并设置 `ANDROP_HUAWEI_REFERENCE_ROOT` 为仓库根目录，详见[华为说明](HUAWEI.md)。源代码发布不等于 App Store、TestFlight 或正式兼容性发布。
