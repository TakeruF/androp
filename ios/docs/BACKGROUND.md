# 后台传输与进度

简体中文 · [English](BACKGROUND.en.md)

从 0.4.0 起，iOS / iPadOS 26 及以上使用 `BGContinuedProcessingTask`，在系统允许的范围内继续已开始的传输，向系统 Live Activity 提供实际字节数与状态。支持的 iPhone 可在 Dynamic Island 展示；不使用远程通知或专用服务器。

## 开始与完成

本体发送在用户选择接收设备时提交持续任务；接收在用户按“受信する”后提交，不在后台自动批准。启动交接期间使用短暂的 UIKit 后台执行宽限。开始后可以切换到主屏幕或其他应用。

进度取自真实传输字节，不按时间估计。ZIP 字节发完后仍需对方确认，接收后仍需完整性检查；这些完成之前不标记成功。系统进度的停止按钮、系统过期通知和应用强制退出会终止传输。系统决定显示更新的频率。

## 共享菜单

1. 在“文件”“照片”等应用共享到 anDrop，选择接收设备。
2. 看到“anDrop本体を開くと送信を開始します”后，按“準備を完了”。
3. 手动打开 anDrop 本体，开始发送；开始后可切换应用。
4. iPad 分屏中本体已打开时，按本体的“準備済みの送信を開始”。

这一版不依赖共享扩展自动打开本体。扩展把文件复制到私有 App Group 的一个交接槽，并保存所选通信方式与路由标识。本体验证文件、件数、大小、名称和任务归属，再重新确认接收设备。互传的跨进程设备匹配使用发现标识，不假设两个进程的蓝牙 UUID 相同。

只允许一个交接任务；取消未选择接收设备的共享会删除准备数据，传输完成、失败、中止后删除本任务的私有副本。过期准备数据在下次使用时清理。本体选中的原文件保持不变，可用于重发。

## 系统限制与验证

系统拒绝后台任务时，应用提示保持本体前台。iOS 26 以前使用前台传输，共享扩展也需要保持打开。这不是常驻后台发现或接收服务。

任务使用唯一的完整标识注册处理器，并声明允许的通配前缀。状态或终态变化会更新系统进度；普通字节更新以约每秒四次为上限。见 [Apple 持续后台处理说明](https://developer.apple.com/documentation/backgroundtasks/performing-long-running-tasks-on-ios-and-ipados)。

实机测试脚本为 `scripts/test-background-device.sh`，从 `ANDROP_DEVELOPMENT_TEAM` 读取团队。它只用设备内的合成 20 MiB TLS 通信测试本体发送、接收确认后的后台接收、共享交接，不操作 OPPO / 华为。结束后恢复正常启动并移除测试辅助应用和运行器，不删除用户历史或文件。需要明确计划测试并解锁设备后才运行。

早期开发构建已在 iPhone 16 看到系统真实字节进度和后台完成。最新版完整实机验证仍待完成；华为后台互操作未验证。见[验证范围](VALIDATION.md)。
