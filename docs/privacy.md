# anDrop 隐私政策

最后更新：2026年11月1日

anDrop 由 **TakeruF** 开发和提供。本政策适用于 macOS 应用及其 Finder 共享扩展，包括 GitHub 分发版和任何 Mac App Store 分发版。两种版本的更新方式有所不同，详见下文。

## 文件与附近设备

anDrop 使用蓝牙发现附近的兼容设备，并通过本地网络收发文件。文件内容及文件名、大小等传输信息会与本次传输涉及的另一台设备交换。文件传输不经过开发者运营的服务器，anDrop 不会自动将文件上传给 TakeruF。

附近设备可以看到你的共享名称，默认名称来自 Mac 的系统电脑名称。发现和连接过程会使用设备标识符、设备类型／厂商信息及本地网络地址。发送或接收端会获得完成传输所需的信息。你可以在设置中修改共享名称。蓝牙和本地网络权限由 macOS 管理。

## 保存在 Mac 上的信息

anDrop 在本机保存设置、已选文件夹的访问书签、设备别名、隐藏设备偏好、已记录的设备及信任记录。信任记录使用协议发送者 ID 或传输公钥的摘要。应用还会在本机保存用于兼容传输的加密身份材料。这些记录不属于 Apple、Android 或厂商账号配对。

本地传输记录可能包含设备名称、文件名、本地路径、日期、传输大小及结果。接收的文件保存在“下载”或你选择的保存文件夹中。共享文件暂存或实况照片转换可能在应用存储空间内生成临时副本；转换后的文件会按你的操作保存或发送。应用不会扫描“照片”图库来建立用户画像。

## 诊断与支持

anDrop 在本机保留有数量上限的近期诊断日志和失败快照，以排查传输问题。其内容可能包括传输阶段、错误代码、文件类型与数量、设备厂商／类型、应用与 macOS 版本，以及传输开始或失败时 Mac 上运行的应用名称和包标识符。应用生成的结构化诊断报告不包含文件内容、文件名、设备名称、网络地址或密钥。

诊断信息不会自动发送。你选择反馈问题后，anDrop 会准备附有报告的邮件草稿；你可以在发送前检查、修改或取消。若发送至 **support@takeruf.com**，TakeruF 将收到你的邮箱地址、正文和附件，包括你自行添加的内容。请勿附上不希望分享的文件或信息。你的邮件服务商也会依据其自身条款处理邮件。

支持信息用于答复请求、调查问题和改进 anDrop。我们仅在这些目的需要期间保留，之后删除；法律要求或解决争议所需的保留除外。你可以通过同一地址申请删除。TakeruF 不出售支持信息，也不将其用于广告。

## 互联网连接与分发渠道

- **GitHub 版：** Sparkle 会检查更新源，并从 GitHub 下载签名更新。自动检查和安装默认开启，可在“设置 → 更新”中关闭。更新请求会向 GitHub 及其分发服务商提供公共 IP 地址、HTTP 客户端／版本信息等常规连接信息。更新请求不附带文件内容、传输记录或诊断报告；Sparkle 系统信息统计已关闭。
- **Mac App Store 版：** 不包含 Sparkle，也不执行其 GitHub 更新检查。更新由 Apple 通过 Mac App Store 提供，适用 Apple 的隐私规则。本项说明该分发构建的行为，不代表应用已在 App Store 上架。
- **主动打开的链接：** 打开本政策、仓库或其他外部链接时，浏览器会连接相应网站，网站可能获得常规连接信息。takeruf.com 上的政策页面与应用的本地文件传输功能是分开的。

anDrop 不包含广告或分析 SDK，不会自动向 TakeruF 发送使用统计，也不需要注册 anDrop 账号。GitHub、Apple、网站托管和邮件服务商会依据各自的政策处理其服务涉及的信息。可参阅 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)和 [Apple 隐私政策](https://www.apple.com/legal/privacy/)。

## 保留、删除与控制

你可以在设置中清除传输记录、移除信任或已记录的设备，并修改别名及隐藏设备偏好。清除传输记录不会删除接收的文件、信任设置、诊断文件或你另外复制的报告。应用内的近期诊断按固定数量上限轮换，而非无限保存。

设置和信任记录会保留，直至你修改、移除或删除应用数据。卸载应用不一定会删除 macOS 容器、偏好设置、旧版 Application Support 数据或保存在容器外的文件。如需删除剩余本地数据，请先退出 anDrop，再从用户资源库中移除其应用容器／偏好设置，以及旧版 `Library/Application Support/anDrop` 数据。保留仍需使用的接收文件或导出报告；从相应保存位置删除不需要的副本。上述操作可能重置权限、设备信任及应用的本地身份。macOS 备份和其他设备上的副本需由你另行管理。

你可以在 macOS 中撤销文件／文件夹、蓝牙、本地网络和通知权限；撤销后，对应功能可能无法使用。退出 anDrop 会停止发现和传输服务。你可以关闭受信任设备自动接收；在“所有人”模式下，未受信任的传入请求仍需确认。

App Sandbox 和文件访问授权将访问范围限制在应用存储、“下载”和你授权的文件／文件夹内。网络及设备保护存在限制，任何软件都无法保证绝对安全；已记录设备不等于经过认证的个人身份。
