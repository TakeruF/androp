# anDrop 1.0.0

anDrop 首个正式版本：通过手机、平板自带的兼容互传功能，与 Mac 收发文件，无需预先连接厂商电脑端应用。

## 使用要求

- Apple Silicon Mac，macOS 14 或更新版本。1.0.0 不提供 Intel 安装包。
- 两台设备开启蓝牙，并连接同一局域网 Wi-Fi。
- 对方设备需支持兼容的互传联盟功能；这不是 Google Quick Share，也不是所有 Android 设备的通用功能。

## 主要功能

- 常驻菜单栏，可从 Finder 的“共享 → anDrop”发送文件；接收文件默认直接保存至“下载”。
- 设备列表显示厂商标志及手机／平板角标，可设置仅保存在 Mac 上的设备别名。
- 发送进度环、百分比、通知及本机传输记录；发送中可切到其他窗口继续工作。
- “所有人”与“仅限受信任的设备”两种接收范围，可从历史记录添加离线设备。
- 默认简体中文，也支持英语；可修改共享名称、保存位置和登录时启动选项。
- 自动检查和下载更新默认开启，下载并验证完成后提示安装；可在设置中关闭，传输期间会推迟检查或重启。
- 纸飞机应用及菜单栏图标；平时隐藏 Dock 图标，与 Petal 同时运行时保留 Dock 图标。

## 安装

下载 `anDrop-1.0.0-arm64.dmg`，打开后将 anDrop 拖入 Applications，再启动应用。首次使用按提示允许蓝牙、本地网络、通知和保存文件夹访问。应用与 DMG 使用 Developer ID 签名；更新订阅文件和更新包另有 EdDSA 签名验证。

## 已验证范围与限制

- 开发阶段已验证 OPPO Find X9 Pro 双向传输并比对哈希；一台 OPPO 平板向 Mac 发送成功。
- 小米、荣耀、vivo 等其他品牌和机型尚未实机验证。厂商标志不代表兼容性保证。
- macOS 14 是构建目标，所有随应用打包的二进制均检查最低系统版本；实际开发验证在 macOS 27.0.1 完成，macOS 14 实机尚未验证。
- “仅限受信任的设备”会拒绝未登记设备的传输请求，但不会向它们隐藏 Mac；它不是 AirDrop 的联系人匹配，也不是加密身份认证。每次接收仍需确认。
- 与 Petal 的共存仍属实验性支持。可能需要在设置中手动修复，或暂时退出 Petal。
- 一次进行一项传输；文件夹请先压缩。Wi-Fi Direct、Google Quick Share、Huawei Share 尚未实现。
- Finder 共享扩展的旧图标可能仍被系统缓存，可稍后重启 Mac；不影响传输。
