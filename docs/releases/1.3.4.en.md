# anDrop 1.3.4

[简体中文](https://github.com/TakeruF/androp/blob/main/docs/releases/1.3.4.md) · English

- Fix sending multiple JPEGs through Finder Share being rejected as duplicate filenames even when the original names differ.
- Preserve original filenames and contents when sharing, while retaining alternative loading methods for Photos and other apps.

Build 13400 passes 322 Python tests, 53 Swift tests and the native Share extension compile/layout test. Actual Finder sharing verified the original names and matching SHA-256 values of four JPEGs, followed by send preparation and ZIP checks. Delivery to the tablet has not been verified for this fix.

Check for updates in anDrop Settings, or download **anDrop-1.3.4-arm64.dmg** and replace anDrop in Applications. Requires an Apple Silicon Mac running macOS 14 or later.
