# anDrop 1.3.6

简体中文 · [English](https://github.com/TakeruF/androp/blob/main/docs/releases/1.3.6.en.md)

- 修复接收完成通知的“在访达中显示”保留此前文件高亮的问题。
- 清除旧选择，选中本次接收文件，并在返回成功前核对完整选择结果。
- 继续复用当前桌面的保存文件夹窗口，保留其大小和位置。

构建编号为 13600。全部 322 项 Python 测试、55 项 Swift 测试及正式 AppModel UI 回归测试通过。用户已确认实际接收通知按钮能切换到接收文件；访达辅助功能检查也确认选中项与一条已完成接收记录一致。本次修复未重新验证不同空间、最小化窗口或多个物理显示器的场景。

在 anDrop 设置中检查更新，或下载 **anDrop-1.3.6-arm64.dmg**，替换“应用程序”中的 anDrop。需要 Apple Silicon Mac 和 macOS 14 或以上。
