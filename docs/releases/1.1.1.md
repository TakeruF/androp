# anDrop 1.1.1

修复点击接收完成通知中的“在访达中显示”时，anDrop 设置窗口可能同时打开并抢到前台的问题。该操作现在仅请求 Finder 显示已接收的文件。

## 安装与更新

- 下载 `anDrop-1.1.1-arm64.dmg`，将 anDrop 拖入 Applications 替换旧版；也可在应用中选择“检查更新…”。
- 支持 Apple Silicon Mac，要求 macOS 14 或更新版本。
- 应用经过 Apple 公证并附带公证票据；应用和 DMG 使用 Developer ID 签名，自动更新另有签名验证。

本次为通知操作修复；未重新进行手机／平板传输测试。自动化与打包验证范围见[测试记录](https://github.com/TakeruF/cn-android-share/blob/main/docs/testing.md)。
