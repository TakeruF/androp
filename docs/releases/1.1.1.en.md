# anDrop 1.1.1

[简体中文](https://github.com/TakeruF/androp/blob/main/docs/releases/1.1.1.md) · English

Fixes Show in Finder on a completed-receive notification also opening and foregrounding anDrop Settings. The action now only asks Finder to reveal received files.

Download anDrop-1.1.1-arm64.dmg and replace the app in Applications, or Check for Updates. Apple Silicon/macOS 14+. The app is notarized/stapled; app/DMG use Developer ID and updates have additional signature verification.

This notification-action fix did not repeat phone/tablet transfers. See [validation](https://github.com/TakeruF/androp/blob/main/docs/testing.en.md) for automation and packaging scope.
