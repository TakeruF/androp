# anDrop 1.2.2

[简体中文](https://github.com/TakeruF/androp/blob/main/docs/releases/1.2.2.md) · English

## Live Photos and moving pictures

- Adds local conversion between Apple Live Photos, Android/OPPO Motion Photos and Huawei moving pictures for sending and receiving. Select a `.pvt` package or a metadata-matched original image and MOV pair to send.
- Receives OPPO's dedicated Live Photo ZIP as a validated `.pvt` package in the selected folder, Downloads by default. After successful conversion, removes the transport ZIP; conversion failure retains it. Ordinary ZIPs remain ordinary files.
- Keeps received Live Photos as files. No automatic Photos import, Photos launch or library-access permission request.

## Photo sharing and compatibility fixes

- Copies Photos/Finder share-provider files while their callback access is valid, before passing them to the main app. Adds legacy shared-file URL and encoded media-data alternatives when the modern file representation is unavailable.
- Wraps share-extension error messages so the full text remains visible above Close.
- Corrects Apple-computer presentation for qualifying Huawei Share discovery records.
- Accepts UTF-8 binary WebSocket control frames, and improves privacy-filtered connection and conversion diagnostics.

## Scope

URL and text sharing are unsupported in both directions. Existing `.txt`, `.url` and `.webloc` files can still be transferred as ordinary files; their contents are not interpreted or opened automatically.

Synthetic media, PhotoKit file-pair validation and protocol tests cover conversion and fallback loading. Recognition in actual OPPO/Huawei galleries, HDR/gainmap preservation, the latest Photos-to-phone retry and recovery from all OPPO connection failures remain unverified. Photos sharing can supply a still image only; export the unmodified image and paired movie when a full Live Photo is not offered. See [Live Photo details](https://github.com/TakeruF/androp/blob/main/docs/live-photos.en.md) and [validation records](https://github.com/TakeruF/androp/blob/main/docs/testing.en.md).

## Update and installation

Check for updates in anDrop Settings, or download **anDrop-1.2.2-arm64.dmg** and replace anDrop in Applications. Requires Apple Silicon and macOS 14 or later. Existing settings and trusted-device records are retained.
