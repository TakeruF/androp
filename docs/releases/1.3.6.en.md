# anDrop 1.3.6

[简体中文](https://github.com/TakeruF/androp/blob/main/docs/releases/1.3.6.md) · English

- Fix Show in Finder from a completed-receive notification leaving previously highlighted files selected.
- Clear the old selection, select the received files and verify the entire selection before reporting success.
- Continue reusing the save-folder window on the current desktop while preserving its size and position.

Build 13600 passes 322 Python tests, 55 Swift tests and the production AppModel UI regression. The user confirmed the actual receive-notification action now switches to the received files; Finder accessibility inspection also confirmed the selected files matched a completed receipt. Separate-Space, minimized-window and multiple-physical-display scenarios were not reverified for this fix.

Check for updates in anDrop Settings, or download **anDrop-1.3.6-arm64.dmg** and replace anDrop in Applications. Requires an Apple Silicon Mac running macOS 14 or later.
