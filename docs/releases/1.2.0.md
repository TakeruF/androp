# anDrop 1.2.0

简体中文 · [English](https://github.com/TakeruF/androp/blob/main/docs/releases/1.2.0.en.md)

**本次更新的主打功能：正式支持华为分享。** 使用手机自带的华为分享，即可与 Mac 双向收发文件，无需安装手机端应用、登录账号、连接 USB 或运行鸿蒙星河互联。两端需开启蓝牙，并连接同一 Wi-Fi／局域网。

## 华为分享正式支持

- 新增华为设备发现、双向文件传输、每次接收确认、进度及历史记录；文件直接保存到所选文件夹，同名文件不覆盖。
- 华为设备可从成功接收的历史记录加入“受信任的设备”，按传输公钥识别并验证私钥持有情况。首次请在“所有人”模式下接收一次文件，再手动添加；每次接收仍需确认。这不是华为账号配对。
- 改善照片缩略图与预览信息兼容性；华为 → Mac 接收最多 16 个文件，单个及合计均不超过 16 MiB。
- Mac → 华为发送最多 16 个文件，单个 4 GiB、合计 16 GiB，使用磁盘快照和分块加密。大容量实现已通过本机通信验证；GiB 级实机传输尚未验证。
- 已在华为 Pura 70／鸿蒙 7完成双向传输及内容校验；其他华为机型的实机覆盖仍待扩展。

## 发送体验与设备管理

- 点击设备立即发送，其他候选设备保持可点击；可向不同设备发送同一批文件，每台设备分别显示进度、结果、取消和重试。
- 并发发送已通过模拟端点及本机 HTTPS／WebSocket 完整性验证；Huawei 与 OPPO 实机同时收妥尚未验证。接收仍独占，不与其他传输同时进行。
- 设备图标右键菜单新增重命名与隐藏；设置中可恢复隐藏设备，重启后保留。名称仅保存在此 Mac。
- 新增华为标志和电脑类型角标；角标与演示截图不代表所有品牌／电脑都已通过兼容性验证。
- 按文件扩展名发送照片、视频、音频等类型信息，改善对方接收提示。

## 自动更新与鸿蒙星河互联

- 自动更新通过签名验证后，在没有传输时自动安装并重启，以通知提示更新结果；传输中推迟安装。关闭自动安装时通过通知提醒新版本。
- **建议完成鸿蒙星河互联中的传输后退出该应用，改用 anDrop 收发文件。** anDrop 可独立完成华为分享文件共享。
- 与鸿蒙星河互联共存仍属实验性支持。若其正在运行且 anDrop 发送或接收失败，会弹窗建议退出后重试。弹窗不会自动退出其他应用，也不将共存判定为失败原因。

## 安装、升级与限制

- 下载 `anDrop-1.2.0-arm64.dmg`，将 anDrop 拖入 Applications 替换旧版；也可在应用中选择“检查更新…”。
- 适用于 Apple Silicon Mac，要求 macOS 14 或更新版本；不提供 Intel 安装包。macOS 14 经过构建兼容性检查，尚未实机验证。
- 应用使用 Developer ID 签名、经过 Apple 公证并附带公证票据；DMG 使用 Developer ID 签名，自动更新另有签名验证。
- 文件夹请先压缩；同批同名文件请分开发送。Google Quick Share 与 Wi-Fi Direct 尚未实现。
- “仅限受信任的设备”过滤接收请求，不向未登记设备隐藏 Mac；每次接收仍需确认。
