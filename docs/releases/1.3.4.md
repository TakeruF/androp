# anDrop 1.3.4

简体中文 · [English](https://github.com/TakeruF/androp/blob/main/docs/releases/1.3.4.en.md)

- 修复通过访达共享多张 JPEG 时，原本不同名的文件被作为同名文件拒绝发送的问题。
- 共享时优先保留原始文件名和内容，同时保留“照片”等应用的备用读取方式。

构建编号为 13400。322 项 Python 测试、53 项 Swift 测试及原生共享扩展编译与布局测试通过。实际访达共享验证了四张 JPEG 的原始名称和 SHA-256 一致性，并完成发送准备及 ZIP 打包检查；本次尚未验证平板接收完成。

在 anDrop 设置中检查更新，或下载 **anDrop-1.3.4-arm64.dmg**，替换“应用程序”中的 anDrop。需要 Apple Silicon Mac 和 macOS 14 或以上。
