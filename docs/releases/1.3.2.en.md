# anDrop 1.3.2

[简体中文](https://github.com/TakeruF/androp/blob/main/docs/releases/1.3.2.md) · English

## Incremental receipt and larger batches

- Android ZIP receives save each completed, verified file while the remaining archive downloads when its layout supports streaming. Other ZIP layouts finish downloading to disk before extracting the remaining files.
- Huawei Share receives use disk staging and save verified files individually. Cancellation or a later failure retains files already saved; incomplete files are removed. Overall completion still requires final protocol validation.
- Remove the previous Huawei product limits of 16 files, 4 GiB per outgoing file / 16 GiB total and 16 MiB total incoming data. DFile wire-format limits, available disk space and peer-device limits still apply; this does not guarantee transfers of arbitrary size.
- Both sharing protocols prepare outgoing files one source at a time in 1 MiB chunks. ZIP work runs off the network event loop, and Huawei receive sockets use bounded read-ahead.
- Raise the Finder Share selection limit from 1,000 to 65,535 items. Each protocol's transfer limits still apply.
- Improve guidance when the other device cannot reach the Mac over the local network, including public Wi-Fi isolation, private networks and hotspot alternatives.

## Validation and compatibility

- Passed 322 Python tests in both development and release environments, 48 Swift tests and 49 tests against the bundled engine code.

- Local tests cover 200-file encrypted Huawei socket transfers, an Android ZIP round trip of about 247 MiB, SHA-256 equality, bounded memory, early file visibility, cancellation, corrupt archives and filename collisions.
- Large-batch Huawei transfers on physical devices, actual Android transfer speeds and the experience on an 8 GB Mac remain unverified. Local socket tests do not establish physical-device throughput or stability.
- Requires an Apple Silicon Mac running macOS 14 or later. Physical macOS 14 and Intel testing remain outstanding.

## Updating and installation

Check for updates in anDrop Settings, or download **anDrop-1.3.2-arm64.dmg** and replace anDrop in Applications. Existing settings, trusted devices and transfer history are retained.
