# anDrop 1.1.0

[简体中文](https://github.com/TakeruF/androp/blob/main/docs/releases/1.1.0.md) · English

Improves transfer reliability and adds failure diagnostics/mail feedback.

## Changes

- During the same negotiation, updated network addresses/ports can replace stale endpoints when connectivity apps such as OPPO Connect run. A busy speed-measurement port no longer prevents trying the transfer connection.
- Trust uses protocol sender identifiers learned from successful receipts instead of rotating Bluetooth UUIDs.
- Finder Share no longer loses recipient-window focus and appears to vanish.
- Failure notifications/history open logs in Settings.
- Diagnostics and Feedback previews/reveals reports or creates a draft to support@takeruf.com with JSON attached. The template asks reproduction, expected behavior, model/OS and VPN/connectivity-app usage; the user reviews and sends.

## Upgrading from 1.0.0

Old trust entries cannot migrate by name. Use Everyone for one successful receipt, enroll the resulting device, then remove old records. Bluetooth rotation then usually needs no enrollment, but changed protocol identities do. Trusted-only filters receipt, not visibility; registered devices still need approval. It is not contact matching or cryptographic authentication.

Reports contain phases/errors/type-count/brand-category/Mac-app versions/running-app samples, not filenames/contents/device names/network addresses/keys. Stored locally, never automatically sent; inspect the attachment before sending. Older failures may have no details.

## Installation and compatibility

Download anDrop-1.1.0-arm64.dmg, replace Applications/anDrop or Check for Updates. Apple Silicon/macOS 14+, no Intel; Bluetooth/same LAN required. App notarized/stapled, app/DMG Developer ID signed, updates additionally verified. Physical OPPO transfers with OPPO Connect and endpoint replacement verified contents, without guaranteeing every model/network/VPN combination. macOS 14 physical/Intel remain untested; no Quick Share/Wi-Fi Direct/Huawei Share in this version.

99 Python/21 Swift tests. See [validation](../testing.en.md) and [diagnostics](../diagnostics.en.md).
