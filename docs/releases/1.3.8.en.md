# anDrop 1.3.8 (unreleased)

[简体中文](1.3.8.md) · English

- Add Settings → **Automatically import pictures and videos to Photos**, off by default. When enabled, newly received pictures, videos and Live Photos are added in the background, with add-only permission required before the option can turn on; revoking permission turns it off.
- Mixed batches import only pictures and videos. PDFs, archives and other files remain in the save folder, and all saved originals are kept.
- Converted moving pictures are imported as one Live Photo without an extra still-image copy. An unsupported or corrupt asset does not stop the remaining media from importing. Import failures show a notification with Show in Finder.
- Automatic updates and save-folder changes wait until pending Photos imports finish. Enabling the option does not import transfer history, and receiving files does not open Photos.
- If Show in Finder fails, report the error in a notification without opening anDrop Settings. This notification is removed after three minutes, like other completed-transfer notifications.
- Turning automatic import off, or choosing Stop Import, finishes the current asset and stops the remaining items. Already imported assets and all saved originals are kept. Progress and added/failed/remaining counts are retained in Settings and recent transfer history; an interrupted batch is not automatically imported again after restart.
- Transfer and Photos-import notifications show percentages directly. Progress reuses the same notification, with quiet Notification Center updates throttled to once every two seconds. Dismissing a progress notification suppresses further progress updates for that transfer; completion and failures can still notify you.

The next build number is 13800. Validation covers 325 Python tests, 62 Swift tests, production AppModel integration, synthetic Live Photo conversion and receive hooks, and English/Chinese settings rendering. Actual writes to a personal Photos library and physical phone-to-Photos imports have not been verified. Notification content, quiet replacement settings, dismissal suppression and stop behavior pass automated tests. The current computer-use host was unavailable, so the actual native notification appearance has not been visually verified.

This version has not been published. The current public release remains [1.3.7](https://github.com/TakeruF/androp/releases/tag/v1.3.7).
