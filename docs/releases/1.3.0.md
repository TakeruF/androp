# anDrop 1.3.0

简体中文 · [English](https://github.com/TakeruF/androp/blob/main/docs/releases/1.3.0.en.md)

## App Sandbox

- 主程序、Finder 共享扩展及内置传输／实况照片工具启用 App Sandbox，将文件访问限制在应用容器、下载目录和明确授权的文件或文件夹。
- Finder 共享通过安全书签传递文件访问权，并明确打开扩展所属的 anDrop。
- 修复华为接收在沙盒内的来源检查和文件隔离属性处理，保留 macOS 的隔离保护。
- 自选接收目录的授权会跨重启保存；缺少或失效时，需要重新选择目录才能接收。**从旧版升级后，非默认保存目录需要重新选择一次。**

## 验证与兼容性

- Pura 70（HarmonyOS 7）和 OPPO Pad 4 Pro 均已完成4 MiB文件往返及 SHA-256 一致性验证；OPPO 单／双文件发送、Finder 共享到 Pura 70 已通过。
- 照片应用的真实 Live Photo 共享及两端图库的动态效果识别仍未完成实机验证。
- 面向 Apple Silicon、macOS 14及以上；macOS 14实机及 Intel 未验证。

## 更新与安装

在 anDrop 设置中检查更新，或下载 **anDrop-1.3.0-arm64.dmg**，替换“应用程序”中的 anDrop。保留现有受信任设备、共享名称和传输历史；Huawei 身份数据迁移到应用容器。自选接收目录请按提示重新选择。
