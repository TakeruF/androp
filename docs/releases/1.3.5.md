# anDrop 1.3.5

简体中文 · [English](1.3.5.en.md)

- “在访达中显示”会复用当前桌面中已打开保存文件夹的窗口，将其置于最前并选中已接收文件。
- 保留复用窗口的大小和位置。如果保存文件夹只在其他桌面打开，则在点击所在的显示器中新建窗口。

构建编号为 13500。访达修改通过 54 项 Swift 测试、正式 AppModel UI 回归测试，以及使用多个合成接收文件的原生沙盒验证。本次未验证实际接收通知按钮、不同空间、最小化窗口或多个物理显示器的场景。

此版本已使用与 1.3.4 相同的 Developer ID 身份在本机安装，设置、可信设备及全部 100 条历史记录保持不变，运行中的设置界面显示 1.3.5。本地构建未重新公证，公开发行版仍为 1.3.4。
