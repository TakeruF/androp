# anDrop 1.3.5

简体中文 · [English](https://github.com/TakeruF/androp/blob/main/docs/releases/1.3.5.en.md)

- “在访达中显示”会复用当前桌面中已打开保存文件夹的窗口，将其置于最前并选中已接收文件。
- 保留复用窗口的大小和位置。如果保存文件夹只在其他桌面打开，则在点击所在的显示器中新建窗口。

构建编号为 13500，322 项 Python 测试及 54 项 Swift 测试通过。访达修改还通过正式 AppModel UI 回归测试，以及使用多个合成接收文件的原生沙盒验证。本次未验证实际接收通知按钮、不同空间、最小化窗口或多个物理显示器的场景。

本地更新保留了设置、可信设备及全部 100 条历史记录，运行中的设置界面显示 1.3.5。

在 anDrop 设置中检查更新，或下载 **anDrop-1.3.5-arm64.dmg**，替换“应用程序”中的 anDrop。需要 Apple Silicon Mac 和 macOS 14 或以上。
