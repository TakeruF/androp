# anDrop 1.0.0

[简体中文](https://github.com/TakeruF/androp/blob/main/docs/releases/1.0.0.md) · English

The first stable release sends files between Mac and compatible built-in phone/tablet sharing, without first connecting a vendor desktop app.

## Requirements

Apple Silicon Mac, macOS 14+, no Intel installer. Both devices need Bluetooth and the same local Wi-Fi. The other device must support compatible Mutual Transfer Alliance sharing, not Google Quick Share or universal Android sharing.

## Features

- Menu-bar app, Finder Share→anDrop, default receipt directly in Downloads.
- Manufacturer logos/phone-tablet badges and Mac-local aliases.
- Progress rings/percentages, notifications/history, continued background sending.
- Everyone/Trusted Devices Only, including offline enrollment from history.
- Default Simplified Chinese and English, sharing name/destination/login startup settings.
- Automatic checking/downloading defaults on, prompting to install after verification; settings can disable it, with checks/relaunch deferred during transfers.
- Paper-plane app/menu icon, Dock hidden normally and retained alongside 鸿蒙星河互联.

## Installation

Open anDrop-1.0.0-arm64.dmg and drag anDrop into Applications. Grant Bluetooth/Local Network/notifications/folder access. App and DMG use Developer ID; feed/archive have additional EdDSA verification.

## Tested scope and limits

Development tests verified OPPO Find X9 Pro in both directions with hashes and an OPPO tablet→Mac. Xiaomi/HONOR/vivo/others are untested; logos do not guarantee compatibility. Bundled binaries target/check macOS 14 but physical tests used27.0.1, not14. Trusted-only refuses unlisted requests without hiding the Mac, is not AirDrop contact matching or cryptographic authentication, and still requires approval. 鸿蒙星河互联 coexistence is experimental, potentially requiring manual discovery repair or quitting 鸿蒙星河互联. One transfer at a time; compress folders first. Wi-Fi Direct/Google Quick Share/Huawei Share were not implemented in this version. Finder may cache an old extension icon until reboot, without affecting transfer.
