# anDrop 1.3.0

[简体中文](https://github.com/TakeruF/androp/blob/main/docs/releases/1.3.0.md) · English

## App Sandbox

- The host, Finder Share extension and bundled transfer/Live Photo tools use App Sandbox. File access is limited to the app container, Downloads and explicitly granted files or folders.
- Finder Share relays file grants through bookmarks and explicitly opens its containing anDrop app.
- Huawei receive source verification and quarantine handling now work within the sandbox while preserving macOS quarantine protection.
- Custom receive-folder grants persist across restarts. Missing or invalid access requires reselection before receiving. **After upgrading from an older version, select a non-default receive folder again once.**

## Validation and compatibility

- Pura 70 (HarmonyOS 7) and OPPO Pad 4 Pro completed 4 MiB round trips with matching SHA-256. Single/two-file OPPO sends and actual Finder Share to Pura 70 passed.
- Actual Live Photo sharing from Photos and animated recognition in both devices' galleries remain unverified on physical devices.
- Requires Apple Silicon and macOS 14 or later. Physical macOS 14 and Intel testing remain outstanding.

## Updating and installation

Check for updates in anDrop Settings, or download **anDrop-1.3.0-arm64.dmg** and replace anDrop in Applications. Existing trusted devices, sharing name and history are retained; Huawei identity data moves into the app container. Reselect a custom receive folder when prompted.
