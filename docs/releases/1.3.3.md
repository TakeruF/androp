# anDrop 1.3.3

简体中文 · [English](https://github.com/TakeruF/androp/blob/main/docs/releases/1.3.3.en.md)

- “在访达中显示”先新建窗口，再将访达置于前台，避免复用另一个空间的已有窗口。
- 在点击所在的显示器上定位新窗口并选中已接收的文件。
- 首次使用时，macOS 会请求控制访达的许可；拒绝后会提示如何重新授权。

构建编号为 13300。322 项 Python 测试、51 项 Swift 测试和 AppModel UI 回归测试通过，并完成两个普通桌面之间的合成文件显示验证。真实接收完成通知的按钮、多台显示器及全屏空间尚未验证。

在 anDrop 设置中检查更新，或下载 **anDrop-1.3.3-arm64.dmg**，替换“应用程序”中的 anDrop。需要 Apple Silicon Mac 和 macOS 14 或以上。
