# anDrop 1.2.3

简体中文 · [English](https://github.com/TakeruF/androp/blob/main/docs/releases/1.2.3.en.md)

## 自动清理通知

- “已发送”“已接收”和“传输失败”通知现在会在送达3分钟后自动从通知中心移除。此前仅自动清理发送成功通知，接收完成和失败通知会一直保留。
- 每条通知按各自的送达时间计时，新通知不会推迟旧通知的清理；打开菜单时也会正常清理。
- 启动 anDrop 或 Mac 从睡眠唤醒时，会清理已过期的通知，包括旧版本留下的通知。应用退出期间无法清理，会在下次启动时处理。
- 应用内传输历史和诊断日志保留。接收确认和正在传输的通知仍保留操作按钮。

## 更新与安装

在 anDrop 设置中检查更新，或下载 **anDrop-1.2.3-arm64.dmg**，替换“应用程序”中的 anDrop。适用于 Apple Silicon、macOS 14 及以上。保留现有设置和受信任设备记录。
