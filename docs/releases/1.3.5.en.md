# anDrop 1.3.5

[简体中文](1.3.5.md) · English

- Show in Finder reuses an existing save-folder window on the current desktop, brings it to the front and selects the received files.
- Keep the reused window's size and position. If the save folder is only open on another desktop, open a new window on the clicked display.

Build 13500. The Finder changes passed 54 Swift tests, the production AppModel UI regression and sandboxed native QA with multiple synthetic received files. The actual receive-notification action, separate-Space scenario, minimized windows and multiple physical displays were not verified in this run.

This version was installed locally with the same Developer ID identity as 1.3.4. Settings, trusted devices and all 100 history entries were preserved, and the running app's Settings reports 1.3.5. The local build has not been newly notarized. Public distribution remains at 1.3.4.
