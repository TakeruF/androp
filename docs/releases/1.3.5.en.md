# anDrop 1.3.5

[简体中文](https://github.com/TakeruF/androp/blob/main/docs/releases/1.3.5.md) · English

- Show in Finder reuses an existing save-folder window on the current desktop, brings it to the front and selects the received files.
- Keep the reused window's size and position. If the save folder is only open on another desktop, open a new window on the clicked display.

Build 13500 passes 322 Python tests and 54 Swift tests. The Finder changes also passed the production AppModel UI regression and sandboxed native QA with multiple synthetic received files. The actual receive-notification action, separate-Space scenario, minimized windows and multiple physical displays were not verified in this run.

The local update preserved settings, trusted devices and all 100 history entries, and the running app's Settings reports 1.3.5.

Check for updates in anDrop Settings, or download **anDrop-1.3.5-arm64.dmg** and replace anDrop in Applications. Requires an Apple Silicon Mac running macOS 14 or later.
