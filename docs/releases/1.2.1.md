# anDrop 1.2.1

简体中文 · [English](https://github.com/TakeruF/androp/blob/main/docs/releases/1.2.1.en.md)

## 受信任设备自动接收

- 在“所有人”和“仅限受信任的设备”两种接收范围下，已登记的受信任设备默认自动接收文件，无需逐次确认。
- 设置新增“自动接收受信任设备的文件”开关；关闭后，每次接收仍需确认。设置会保留到下次启动。
- 同时支持互传联盟发送者 ID 和华为分享传输公钥登记。新设备仍需先在“所有人”模式下确认接收一次，再手动添加为受信任设备。
- “所有人”模式下，未受信任的设备始终需要确认；“仅限受信任的设备”仍拒绝它们的请求。接收范围不影响附近可见性。
- 自动接收省略批准提示；开始传输、完成或失败时仍会通知，进度与取消仍在菜单栏可用。

互传联盟使用对方自行提供的发送者 ID，此便利筛选不是加密身份认证；华为分享在每次握手中校验登记公钥的私钥持有。设备标识或公钥变化后，需重新接收并添加。

## 更新与安装

在 anDrop 设置中检查更新，或下载 **anDrop-1.2.1-arm64.dmg** 并替换“应用程序”中的 anDrop。适用于 Apple Silicon、macOS 14 及以上。首次升级到本版本时，受信任设备自动接收默认开启，可随时关闭。

沿用 1.2.0 的华为分享、并行发送和设备管理功能。更新了中英文说明及设置截图。测试范围与限制见[测试记录](https://github.com/TakeruF/androp/blob/main/docs/testing.md)。
