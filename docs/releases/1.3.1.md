# anDrop 1.3.1

简体中文 · [English](https://github.com/TakeruF/androp/blob/main/docs/releases/1.3.1.en.md)

## 接收稳定性

- 修复接收完成后 Mac 仍短暂显示为忙碌，导致 Android 紧接着再次发送时失败的问题。
- 初始连接缺少详细错误编号时，也会进行有界重试，改善短暂连接故障后的恢复。最多尝试四次，总计不超过十秒；不会重放已开始的文件传输。

## 验证与兼容性

- 已在 OPPO 平板上确认四次连续发送到 Mac 成功。
- 305 项 Python 测试通过，包括延迟关闭连接时立即恢复空闲状态、保护下一次接收和连接重试的回归测试。
- 需要 Apple Silicon Mac 和 macOS 14 或以上。

## 更新与安装

在 anDrop 设置中检查更新，或下载 **anDrop-1.3.1-arm64.dmg**，替换“应用程序”中的 anDrop。保留现有设置、受信任设备和传输历史。
