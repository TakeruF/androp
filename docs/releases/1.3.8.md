# anDrop 1.3.8（尚未发布）

简体中文 · [English](1.3.8.en.md)

- 新增设置项 **“自动将照片和视频导入‘照片’”**，默认关闭。开启后，新收到的照片、视频和实况照片会在后台添加到“照片”，开启时请求“仅添加”许可，获得许可后才能开启；撤销许可后会自动关闭。
- 混合批次仅导入照片和视频。PDF、压缩包等其他文件仍保存在接收文件夹，所有已保存的原始文件均会保留。
- 转换后的动态照片作为一张实况照片导入，不另加静态副本。不支持或损坏的媒体不会阻止其余媒体导入；失败通知提供“在访达中显示”操作。
- 自动更新与保存文件夹更改会等待待处理的照片导入完成。开启此选项不会追溯导入传输历史，接收时也不会打开“照片”应用。
- “在访达中显示”失败时，通过通知说明错误，不打开 anDrop 设置。该通知与其他已完成传输通知一样，在三分钟后移除。
- 关闭自动导入或选择“停止导入”后，完成当前一项即停止剩余项；已导入的资源和所有已保存的原始文件均保留。设置与最近传输记录保留进度及添加、失败、剩余数量；重启后不会自动重新导入被中断的批次。
- 传输及照片导入通知直接显示百分比。进度复用同一条通知，在通知中心静默更新，最多每两秒一次。关闭进度通知后，该传输不再推送进度更新；完成和失败仍可通知。

下一构建编号为 13800。验证范围包括 325 项 Python 测试、62 项 Swift 测试、正式 AppModel 集成、合成实况照片转换与接收流程，以及中英文设置界面渲染。尚未验证向个人照片图库实际写入，或手机实机接收到“照片”的完整流程。 通知内容、静默替换设置、关闭后停止更新及导入停止行为已通过自动测试；本次计算机操作服务不可用，尚未目视验证原生通知的实际显示效果。

此版本尚未发布，当前公开版本仍为 [1.3.7](https://github.com/TakeruF/androp/releases/tag/v1.3.7)。
