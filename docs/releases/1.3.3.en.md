# anDrop 1.3.3

[简体中文](https://github.com/TakeruF/androp/blob/main/docs/releases/1.3.3.md) · English

- Show in Finder creates a new window before bringing Finder forward, avoiding reuse of an existing window on another Space.
- Position the new window on the clicked display and select the received files.
- macOS requests permission to control Finder on first use; a denied request explains how to enable it again.

Build 13300 passes 322 Python tests, 51 Swift tests, the AppModel UI regression and a synthetic file-reveal check across two ordinary desktops. The actual received-transfer notification action, multiple displays and fullscreen Spaces remain unverified.

Check for updates in anDrop Settings, or download **anDrop-1.3.3-arm64.dmg** and replace anDrop in Applications. Requires an Apple Silicon Mac running macOS 14 or later.
